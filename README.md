# 💳 Одобрено! — Интеллектуальный сервис оценки кредитоспособности

> Веб-сервис для мгновенного скоринга пользователей и автоматической оценки кредитных рисков на базе FastAPI и ИИ-алгоритмов.

---

## 📌 Описание проекта

**«Одобрено!»** решает проблему долгого, бюрократизированного и непрозрачного кредитного андеррайтинга. 

Традиционные процессы проверки в банках занимают от нескольких часов до суток, опираются на устаревшие регламенты и приводят к высокому уровню отказов (до 83% по данным НБКИ) без объяснения причин. При этом просроченная задолженность россиян превышает 1.6 трлн рублей из-за ошибок стандартных протоколов оценки.

### Ключевой функционал сервиса:
* ⚡ **Мгновенный скоринг:** Асинхронный обработчик на FastAPI оценивает финансовый профиль за доли секунды.
* 🤖 **Объяснимый ИИ (Explainable AI):** Сервис не просто выдает вердикт *«Одобрено»* / *«Отказано»*, но и предоставляет детальное текстовое пояснение, индикаторы риска и рекомендации по оптимизации условий.
* 🎛 **Удобный UI без мороки с документами:** Минималистичный веб-интерфейс позволяет в пару кликов ввести финансовые показатели и наглядно увидеть свой профиль.
* 📑 **OpenAPI Документация:** Встроенная автодокументация API via Swagger для быстрой B2B-интеграции.
